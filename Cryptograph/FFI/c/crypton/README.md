# Vendored crypton C

These SHA3/Keccak and RIPEMD sources and support headers are copied from
PlutusCoreBlaster's `cryptograph-ffi` branch at
`b12153961f282a855d918a69fb05209a8f0786b6` (PR13). Only trailing whitespace has been normalized. Their original Vincent Hanquez copyright
notices and BSD license terms remain in each file; `LICENSE` reproduces the terms for binary
distributions. The wrapper in the parent directory is adapted separately.

Keep the notices when redistributing sources and include `LICENSE` with distributed binaries.
